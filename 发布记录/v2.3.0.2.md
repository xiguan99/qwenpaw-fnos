## 本版改动

1. `scripts/vendor/trim-cli` 删除 → `scripts/vendor/fnos-cli/` = 0.6.2 全树 + `bin/fnos-cli-0.6.2-linux-x64.gz`（随包预置二进制）。
2. `fnpack/cmd/main`：新增 `ensure_fnos_skill()`——启动时把 vendor 技能原子部署到 `${TRIM_PKGVAR}/data/skill_pool/fnos-cli`（版本戳 `.fnos-skill-version` 幂等），并 gunzip 预置 CLI 缓存 `${HOME}/.cache/fnos-cli/0.6.2/linux-x64/fnos-cli`（gz sha256 + 解包尺寸 + binary sha256 三重校验；失败退让首跑联网下载，不阻塞启动）；PATH 头插技能 scripts。manifest 字段解析用**单行 JSON + jget**（教训：tab 型 IFS 的 `read` 会折叠空字段导致字段左移、校验永不相等——禁用 TSV 传字段）。
3. `scripts/shell/fnshell.py`（网关壳=授权卡后端）fnos 段移植 0.6.2 两段式：`login --authorize-only --agent-name qwenpaw` 一次性出 URL（Host 头替换，手机可用）→ `login --code`；logout 清 profiles；`_fnos_parse_json` 大括号平衡扫描（0.6.2 多行 JSON）；`system info` rc 判授权；UI 契约字段不变（panel_dist 未动）。
4. `scripts/build.sh`：vendor 整体重置 + 构建前清 `__pycache__`（曾把 .pyc 带进 app.tgz）。
5. 版本 2.3.0.1 → 2.3.0.2（VERSION / fnpack/manifest / README）。
